# AWS Kubernetes GitOps Platform

A production-style Kubernetes platform on AWS provisioned with Terraform and KOPS, with GitOps deployments using Argo CD, service mesh capabilities through Istio, CI/CD automation with Jenkins, and observability using Prometheus, Grafana, Kiali and Jaeger.

The project demonstrates infrastructure automation, Kubernetes cluster provisioning, application delivery, monitoring, security, and multi-environment deployment practices across staging and production.
